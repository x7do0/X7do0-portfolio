# أنواع معاينات المشاريع

أصبحت معاينة كل مشروع مستقلة عن كونه مشروعًا رئيسيًا أو ثانويًا. يحدد المشروع نوع المعاينة من ملفات المحتوى عبر الحقل:

```json
"previewKind": "generic"
```

## الأنواع المدعومة

- `workflow` — المعاينة التفاعلية الخاصة بـ Enterprise Workflow.
- `academy` — معاينة المنصة التعليمية.
- `generic` — معاينة عامة وآمنة لأي مشروع جديد إلى أن تتوفر له معاينة مخصصة.

## إضافة مشروع جديد

استخدم `generic` افتراضيًا عند إضافة مشروع لا يملك تجربة بصرية مخصصة:

```json
{
  "slug": "new-project",
  "title": "اسم المشروع",
  "summary": "الوصف المختصر المعتمد",
  "featured": false,
  "previewKind": "generic",
  "cta": "استكشف المشروع",
  "media": [],
  "caseStudy": []
}
```

يجب استخدام نفس `previewKind` في الملفين العربي والإنكليزي. يتحقق التطبيق من القيمة عند تحميل المحتوى، ويرفض أي نوع غير مدعوم برسالة واضحة بدل عرض معاينة خاطئة.

## إضافة نوع مخصص مستقبلًا

عند اعتماد تصميم خاص لمشروع جديد:

1. أضف الحالة الجديدة داخل `ProjectPreview.razor`.
2. أضف اسم النوع إلى `SupportedPreviewKinds` داخل `PortfolioContentService`.
3. حدّث `previewKind` في ملفي المحتوى.

بهذا تبقى بطاقات الصفحة الرئيسية وصفحات المشاريع تستخدم نفس منطق العرض بدون تكرار.
