# إدارة أقسام الصفحة الرئيسية

ترتيب الأقسام الظاهرة بعد الواجهة الرئيسية يُدار من الخاصية `homeSections` داخل ملفي المحتوى:

- `src/X7do0.Portfolio/Content/portfolio.ar.json`
- `src/X7do0.Portfolio/Content/portfolio.en.json`

القيمة المعتمدة حاليًا:

```json
"homeSections": [
  "projects",
  "skills",
  "technologies",
  "education",
  "knowledge",
  "contact"
]
```

## الأقسام المدعومة

- `projects`
- `skills`
- `technologies`
- `education`
- `knowledge`
- `contact`

يمكن تغيير ترتيب الأقسام أو حذف قسم مؤقتًا من المصفوفة بدون تعديل `Home.razor` أو إعادة بناء الصفحة.

## قواعد الحماية

- يجب تحديث الترتيب نفسه في النسختين العربية والإنكليزية.
- لا يجوز تكرار المعرّف داخل المصفوفة.
- لا تُقبل معرّفات غير مدعومة.
- يجب أن يبقى `projects` أول قسم، التزامًا بالقرار المعتمد أن تأتي المشاريع المختارة مباشرة بعد الواجهة الرئيسية.
- الواجهة الرئيسية نفسها تبقى ثابتة في البداية ولا تدخل ضمن هذه المصفوفة.

عرض كل قسم موجود داخل المكوّن:

`src/X7do0.Portfolio/Components/Shared/HomeSectionRenderer.razor`

عند إضافة **نوع قسم جديد بالكامل**، يُضاف له معرّف ومكوّن عرض مرة واحدة، وبعدها يمكن التحكم بمكانه من JSON.
