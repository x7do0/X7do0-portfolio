# دليل إدارة محتوى البورتفوليو

صُمّم الموقع بحيث تُضاف معظم المعلومات من ملفات المحتوى، بدون إنشاء مكوّن جديد لكل مشروع أو مهارة.

## الملفات الأساسية

- العربية: `src/X7do0.Portfolio/Content/portfolio.ar.json`
- الإنجليزية: `src/X7do0.Portfolio/Content/portfolio.en.json`
- شكل البيانات: `src/X7do0.Portfolio/Models/PortfolioContent.cs`

يجب تحديث النسختين العربية والإنجليزية معًا، مع الحفاظ على نفس `slug` للمشروع في الملفين.

## إضافة مشروع

أضف عنصرًا جديدًا داخل مصفوفة `projects` في الملفين:

```json
{
  "slug": "project-slug",
  "title": "اسم المشروع",
  "summary": "الوصف المختصر المعتمد",
  "featured": false,
  "cta": "استكشف المشروع"
}
```

بعد الحفظ سيظهر المشروع تلقائيًا في الصفحة الرئيسية، وستتوفر له صفحة على المسار:

```text
/projects/project-slug
```

لا حاجة إلى تعديل صفحة `Home.razor` أو إنشاء صفحة Razor مستقلة لكل مشروع.

## إضافة مهارة

أضف النص الجديد داخل:

```text
skillsSection.items
```

الترتيب داخل المصفوفة هو ترتيب الظهور في الموقع.

## إضافة تقنية

- لإضافة تقنية إلى مجموعة موجودة، أضفها داخل `items` للمجموعة المطلوبة.
- لإضافة تصنيف جديد، أضف عنصرًا جديدًا إلى `technologiesSection.groups` يحتوي `title` و`items`.

## تعديل النصوص العامة

توجد نصوص الواجهة الرئيسية، المشاريع، التعليم، مشاركة المعرفة، التواصل، صفحات المشاريع، والسيرة الذاتية داخل الملفين نفسيهما.

## إضافة روابط التواصل والحسابات

توجد الروابط داخل `contact.primaryLinks` و`contact.socialLinks`، بالشكل التالي:

```json
{
  "label": "GitHub",
  "url": "https://github.com/x7do0",
  "kind": "secondary"
}
```

- عندما تكون `url` فارغة، يظهر العنصر بحالة غير مفعّلة بدون رابط وهمي.
- عند إضافة رابط صحيح، يتحول العنصر تلقائيًا إلى رابط قابل للضغط.
- استخدم `kind: "primary"` للزر الرئيسي و`kind: "secondary"` لبقية الأزرار.
- رابط قناة YouTube يوضع داخل `knowledge.channelUrl`.
- لا حاجة إلى تعديل `Home.razor` عند إضافة البريد أو LinkedIn أو YouTube أو Instagram.

## الصور والفيديوهات والملفات

عند اعتماد المواد الحقيقية لاحقًا، يجب إضافتها إلى نموذج المحتوى بدل تثبيتها داخل مكونات العرض. ينطبق ذلك على:

- فيديوهات قسم مشاركة المعرفة.
- ملفات السيرة الذاتية PDF.
- صور ومعاينات المشاريع.

## التحقق من سلامة المحتوى

تقرأ `PortfolioContentService` ملفات JSON وتتحقق من البيانات قبل عرضها.

يوقف التطبيق تحميل الملف ويعرض خطأ واضحًا عند وجود مشكلة مثل:

- اسم أو وصف أساسي فارغ.
- مشروع بدون `slug` أو عنوان أو وصف.
- تكرار `slug` بين مشروعين.
- مهارة فارغة.
- مجموعة تقنيات بلا عنوان أو بلا عناصر.

في بيئة التطوير لا يُحفظ المحتوى داخل Cache، لذلك يكفي تعديل JSON وإعادة تحميل الصفحة. في بيئات النشر يُستخدم Cache لتقليل القراءة المتكررة للملفات.

## قواعد مهمة

- لا تستخدم `slug` مكررًا.
- لا تغيّر `slug` بعد نشر رابط المشروع إلا عند إضافة إعادة توجيه.
- لا تضف معلومات غير معتمدة لإكمال الشكل.
- حافظ على ترتيب المهارات والمشاريع وفق سجل البورتفوليو.
- تقنيات المشروع يمكن ذكرها في دراسة الحالة بدون تحويلها تلقائيًا إلى مهارات شخصية.
- لا تضف رابطًا تجريبيًا أو وهميًا؛ اترك `url` فارغة إلى أن يُعتمد الرابط الحقيقي.
