# دليل إدارة محتوى البورتفوليو

صُمّم الموقع بحيث تُضاف معظم المعلومات من ملفات المحتوى، بدون إنشاء مكوّن جديد لكل مشروع أو مهارة.

## الملفات الأساسية

- العربية: `src/X7do0.Portfolio/Content/portfolio.ar.json`
- الإنجليزية: `src/X7do0.Portfolio/Content/portfolio.en.json`
- شكل البيانات: `src/X7do0.Portfolio/Models/PortfolioContent.cs`

يجب تحديث النسختين العربية والإنجليزية معًا، مع الحفاظ على نفس `slug` للمشروع في الملفين.

## إضافة مشروع

أضف عنصرًا جديدًا داخل مصفوفة `projects` في الملفين:

```json
{
  "slug": "project-slug",
  "title": "اسم المشروع",
  "summary": "الوصف المختصر المعتمد",
  "featured": false,
  "cta": "استكشف المشروع"
}
```

بعد الحفظ سيظهر المشروع تلقائيًا في الصفحة الرئيسية، وستتوفر له صفحة على `/projects/project-slug` بدون تعديل `Home.razor`.

## إضافة مهارة أو تقنية

- المهارات: أضف النص داخل `skillsSection.items`، وترتيب المصفوفة هو ترتيب الظهور.
- التقنية: أضفها إلى `technologiesSection.groups[].items`، أو أضف مجموعة جديدة تحتوي `title` و`items`.

## إضافة روابط التواصل

توجد الروابط داخل `contact.primaryLinks` و`contact.socialLinks`:

```json
{ "label": "GitHub", "url": "https://github.com/x7do0", "kind": "secondary" }
```

عندما تكون `url` فارغة، يظهر العنصر بحالة غير مفعّلة. عند إضافة رابط صحيح، يصبح قابلًا للضغط تلقائيًا.

## إضافة فيديوهات مشاركة المعرفة

يوضع رابط القناة داخل `knowledge.channelUrl`، وتضاف الفيديوهات داخل `knowledge.videos`:

```json
{
  "title": "عنوان الفيديو المعتمد",
  "url": "https://youtube.com/watch?v=...",
  "thumbnailUrl": "https://..."
}
```

- يعرض الموقع أول ثلاثة فيديوهات فقط.
- `thumbnailUrl` اختياري.
- عندما تكون المصفوفة فارغة، تبقى العناصر المؤقتة ظاهرة بدون روابط وهمية.

## إضافة ملف السيرة الذاتية

يوضع مسار أو رابط PDF داخل `resume.pdfUrl`:

```json
"pdfUrl": "/files/resume-ar.pdf"
```

عند ترك القيمة فارغة يبقى زر التحميل غير مفعّل. عند إضافة الرابط، يظهر خيارا العرض والتحميل تلقائيًا.

## التحقق من سلامة المحتوى

تقرأ `PortfolioContentService` ملفات JSON وتتحقق من البيانات قبل عرضها، ومنها الحقول الأساسية، وتكرار `slug`، والمهارات الفارغة، ومجموعات التقنيات الناقصة.

في بيئة التطوير لا يُحفظ المحتوى داخل Cache، لذلك يكفي تعديل JSON وإعادة تحميل الصفحة. في بيئات النشر يُستخدم Cache لتقليل القراءة المتكررة.

## قواعد مهمة

- لا تستخدم `slug` مكررًا.
- لا تغيّر `slug` بعد نشر رابط المشروع إلا عند إضافة إعادة توجيه.
- لا تضف معلومات غير معتمدة لإكمال الشكل.
- حافظ على ترتيب المهارات والمشاريع وفق سجل البورتفوليو.
- لا تضف رابطًا تجريبيًا أو وهميًا؛ اترك القيمة فارغة إلى أن يُعتمد الرابط الحقيقي.
