# بنية مشروع x7do0 Portfolio

## الهدف

البنية مصممة حتى يبقى المحتوى منفصلًا عن العرض، وتكون إضافة مشروع أو مهارة أو تقنية أو رابط ممكنة بأقل تعديل للكود.

## طبقات المشروع

### 1. المحتوى

المصدر الأساسي للنصوص والبيانات:

- `src/X7do0.Portfolio/Content/portfolio.ar.json`
- `src/X7do0.Portfolio/Content/portfolio.en.json`

تحتوي هذه الملفات على الهوية، الواجهة الرئيسية، المشاريع، المهارات، التقنيات، التعليم، مشاركة المعرفة، التواصل، وصفحات المشاريع والسيرة.

### 2. نماذج البيانات

الملف:

- `src/X7do0.Portfolio/Models/PortfolioContent.cs`

يحدد شكل البيانات التي تُقرأ من JSON. عند إضافة نوع محتوى جديد، يُضاف النموذج هنا أولًا ثم تُحدّث نسختا المحتوى.

### 3. خدمة المحتوى

الملف:

- `src/X7do0.Portfolio/Services/PortfolioContentService.cs`

مسؤول عن:

- اختيار ملف العربية أو الإنجليزية.
- قراءة JSON وتحويله إلى نماذج C#.
- التحقق من الحقول الأساسية.
- منع تكرار `slug` للمشاريع.
- عدم تخزين المحتوى مؤقتًا أثناء التطوير، حتى تظهر تعديلات JSON بعد إعادة تحميل الصفحة.
- استخدام Cache في البيئات غير التطويرية.

### 4. مكونات العرض القابلة لإعادة الاستخدام

داخل:

- `src/X7do0.Portfolio/Components/Shared`

المكونات الحالية:

- `WorkflowPreview.razor` — العرض التفاعلي للمشروع الرئيسي.
- `ProjectShowcase.razor` — طريقة عرض المشروع في الصفحة الرئيسية.
- `SectionHeading.razor` — عنوان موحّد للأقسام.
- `TechnologyGroups.razor` — عرض مجموعات التقنيات من البيانات.
- `SeoHead.razor` — عنوان الصفحة ووصفها وبيانات Open Graph الأساسية.

### 5. الصفحات

- `Home.razor` — يركب الصفحة الرئيسية من المكونات والبيانات.
- `Project.razor` — صفحة ديناميكية واحدة لجميع المشاريع حسب `slug`.
- `Resume.razor` — صفحة السيرة المبنية من نفس بيانات الموقع.

## قاعدة التوسعة

عند إضافة عنصر محتوى عادي، ابدأ بملفات JSON ولا تعدّل مكونات Razor إلا إذا كان المطلوب نوع عرض جديدًا فعلًا.

أمثلة لا تتطلب تعديل الصفحة:

- إضافة مشروع جديد.
- إضافة مهارة.
- إضافة تقنية أو مجموعة تقنيات.
- تفعيل رابط تواصل.
- تعديل نص أو ترجمة.

أمثلة قد تتطلب مكوّنًا جديدًا:

- إضافة نوع معاينة مختلف كليًا لمشروع.
- إضافة قسم جديد بتركيب بصري غير موجود.
- إضافة فيديوهات أو صور ببيانات وخصائص جديدة.

## قواعد الصيانة

- لا تثبّت محتوى مهني داخل مكونات Razor عندما يمكن وضعه في JSON.
- حافظ على نفس `slug` في العربية والإنجليزية.
- استخدم المكونات المشتركة بدل نسخ نفس HTML بين الصفحات.
- لا تضف بيانات وهمية لتعبئة التصميم.
- لا تربط رابطًا قبل اعتماد الرابط الحقيقي.
- لا تضف GitHub Actions أو CI قبل مرحلة الإكمال النهائي حسب القرار المعتمد.
