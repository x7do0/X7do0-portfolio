# x7do0 Portfolio

المستودع الرسمي للبورتفوليو الشخصي الخاص بـ **حيدره مهند** والهوية الرقمية **x7do0**.

سيُبنى الموقع باستخدام **ASP.NET Core وBlazor على .NET 10**، مع بنية محتوى قابلة للتوسعة، ودعم كامل للعربية والإنجليزية واتجاهي RTL وLTR.

> يجري التطوير على فروع مستقلة، وتُؤجَّل إعدادات CI والاختبارات النهائية إلى مرحلة الإكمال النهائي.
