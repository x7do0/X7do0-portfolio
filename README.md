# x7do0 Portfolio

البورتفوليو الرسمي لـ **حيدره مهند** والهوية الرقمية **x7do0**.

## التقنية

- ASP.NET Core Blazor Web App
- .NET 10
- Interactive Server rendering
- محتوى عربي وإنكليزي منفصل وسهل التعديل
- تصميم RTL/LTR متجاوب
- صفحات مشاريع ديناميكية تعتمد على `slug`
- مكونات عرض مشتركة قابلة لإعادة الاستخدام
- بيانات SEO لكل صفحة مع Canonical وOpen Graph
- `sitemap.xml` و`robots.txt` ديناميكيان
- تحقق تلقائي من سلامة ملفات المحتوى

## التشغيل محليًا

```bash
dotnet run --project src/X7do0.Portfolio/X7do0.Portfolio.csproj
```

## الصفحات والمسارات الحالية

- `/` — الصفحة الرئيسية.
- `/projects/{slug}` — صفحة ديناميكية لأي مشروع موجود داخل ملفات المحتوى.
- `/resume` — السيرة الذاتية المبنية من المعلومات المعتمدة الحالية.
- `/sitemap.xml` — خريطة موقع تتحدث تلقائيًا عند إضافة مشروع.
- `/robots.txt` — تعليمات محركات البحث ورابط خريطة الموقع.

## إضافة المحتوى مستقبلًا

معظم محتوى الموقع موجود في:

- `src/X7do0.Portfolio/Content/portfolio.ar.json`
- `src/X7do0.Portfolio/Content/portfolio.en.json`

إضافة مشروع أو مهارة أو تقنية جديدة تتم بتحديث ملفات المحتوى بدل إعادة بناء الصفحة أو تكرار المكونات. المشروع الجديد يظهر تلقائيًا في الصفحة الرئيسية وصفحته المستقلة وخريطة الموقع.

أثناء التطوير، لا تُخزَّن ملفات المحتوى مؤقتًا، لذلك تظهر تعديلات JSON بعد إعادة تحميل الصفحة. عند وجود حقل أساسي فارغ أو `slug` مكرر، يعرض التطبيق خطأ واضحًا بدل تشغيل محتوى غير سليم.

## حالة التنفيذ

- التطوير يتم على فرع مستقل وDraft Pull Request.
- لم تُضف GitHub Actions أو CI.
- الاختبارات النهائية مؤجلة إلى مرحلة الإكمال النهائي حسب القرار المعتمد.
- روابط الحسابات والفيديوهات وملفات PDF الحقيقية ستُربط بعد اعتمادها.
- تفاصيل دراسات الحالة الكاملة ستُكتب بعد جمع المعلومات الدقيقة لكل مشروع.
