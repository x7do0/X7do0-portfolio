# x7do0 Portfolio

البورتفوليو الرسمي لـ **حيدره مهند** — مطور برمجيات متخصص في Backend.

الموقع Static ومهيأ للنشر المباشر على GitHub Pages، ويعتمد على Semantic HTML وModern CSS وVanilla JavaScript من دون تبعيات Production أو Build step.

## ما يقدمه الموقع

- صفحة رئيسية عربية/إنكليزية ضمن حاوية بعرض أقصى `1120px`.
- تعريف مباشر بالاسم والتخصص وقسم About وسيرة مختصرة داخل الصفحة.
- عرض مدمج لأربعة مشاريع بلقطات حقيقية ومعلومات مستندة إلى مستودعاتها.
- فتح الـInteractive Demos داخل صفحة كل مشروع فقط عبر `iframe` مؤجل التحميل.
- قسم مهارات بصري وتقنيات بعلامات سريعة القراءة.
- دعم RTL/LTR والموبايل و`prefers-reduced-motion`.
- صفحات تفاصيل منفصلة للمشاريع وصفحة Resume قابلة للفهرسة.

## التشغيل محلياً

ملفات المحتوى تُحمّل عبر `fetch`، لذلك يجب تشغيل خادم Static:

```powershell
python -m http.server 8080
```

ثم افتح `http://localhost:8080/`.

## المسارات

- `/` و`/?lang=en` — الصفحة الرئيسية.
- `/projects/{slug}/` — تفاصيل المشروع ومكان تشغيل الـDemo داخل الصفحة.
- `/demos/{slug}/` — المحاكاة المستقلة المستخدمة داخل الـiframe.
- `/resume/` — السيرة داخل الموقع.
- `/404.html` — صفحة غير موجودة ثنائية اللغة.

المشاريع المعتمدة هي:

- `enterprise-workflow`
- `coding-academy`
- `mahsoob`
- `masroofi`

## إدارة المحتوى

المصدران المعتمدان للنصوص والبيانات:

- `content/portfolio.ar.json`
- `content/portfolio.en.json`

يجب تحديثهما معاً والحفاظ على نفس `slug` وترتيب المشاريع. روابط التواصل أو ملف PDF غير المتوفرة تبقى فارغة ولا تظهر للزائر؛ لا تُستخدم بيانات وهمية بدلاً منها.

لقطات المشاريع موجودة في `assets/projects/`. لقطة محسوب موصوفة بوضوح كمحاكاة مصدرية، أما بقية اللقطات فمن الواجهات الفعلية أو النسخة المنشورة.

## Interactive Demos

الـDemos محاكاة لأهم تدفق في كل مشروع وليست نسخاً كاملة من التطبيقات الأصلية. بياناتها تجريبية وحالتها محلية في المتصفح ولا تحتوي على حسابات أو Backend حقيقي.

- Enterprise Workflow: إنشاء طلب، إرساله، تبديل الدور، ثم الموافقة.
- Coding Academy: بطاقات موضوعات، درس، تمرين، ثم تحديث التقدم.
- Mahsoob: إضافة منتج، استلام المبلغ، وإصدار إيصال.
- Masroofi: إضافة مصروف، تحديث الرصيد، ثم حذف العملية.

## الاختبارات

```powershell
npm install
npm run test:e2e
```

تغطي Playwright الصفحة الرئيسية على الديسكتوب والموبايل، العربية والإنكليزية، عدم وجود Horizontal Overflow، انتقال التجربة إلى صفحة المشروع وفتحها هناك، صفحات التفاصيل والسيرة، التدفقات التفاعلية الأربعة، ومسارات SEO العامة.

## SEO والنشر

- `sitemap.xml` يفهرس الصفحة الرئيسية والسيرة وصفحات المشاريع.
- `robots.txt` يستبعد `/demos/` لأنها محاكاة وليست صفحات المحتوى الأساسية.
- النشر من جذر فرع `main` عبر GitHub Pages وملف `.nojekyll`.
