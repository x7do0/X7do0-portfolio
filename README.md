# x7do0 Portfolio

البورتفوليو الرسمي لـ **حيدره مهند** والهوية الرقمية **x7do0**.

## التقنية

- ASP.NET Core Blazor Web App
- .NET 10
- Interactive Server rendering
- محتوى عربي وإنكليزي منفصل وسهل التعديل
- تصميم RTL/LTR متجاوب
- روابط لغة قابلة للمشاركة والفهرسة مع Canonical و`hreflang`
- صفحات مشاريع ديناميكية تعتمد على `slug`
- مكونات عرض مشتركة قابلة لإعادة الاستخدام
- بيانات SEO لكل صفحة مع Canonical وOpen Graph
- بيانات JSON-LD منظمة لهوية حيدره ومشاريع البورتفوليو
- `sitemap.xml` و`robots.txt` ديناميكيان
- تحقق تلقائي من سلامة ملفات المحتوى
- تحقق بنيوي بين النسختين العربية والإنكليزية
- تقرير مستقل لجاهزية المحتوى قبل الإطلاق
- دعم اختياري للاستضافة خلف Reverse Proxy أو Tunnel
- Web App Manifest وأيقونة متصفح موحدة بهوية x7do0

## التشغيل محليًا

```bash
dotnet run --project src/X7do0.Portfolio/X7do0.Portfolio.csproj
```

## الصفحات والمسارات الحالية

- `/` — الصفحة الرئيسية العربية الافتراضية.
- `/?lang=en` — النسخة الإنكليزية القابلة للمشاركة.
- `/projects/{slug}` — صفحة ديناميكية لأي مشروع موجود داخل ملفات المحتوى.
- `/resume` — السيرة الذاتية المبنية من المعلومات المعتمدة الحالية.
- `/sitemap.xml` — خريطة موقع تتحدث تلقائيًا عند إضافة مشروع، وتشمل روابط العربية والإنكليزية.
- `/robots.txt` — تعليمات محركات البحث ورابط خريطة الموقع.
- `/healthz` — يفحص تحميل المحتوى وسلامة التطابق البنيوي بين العربية والإنكليزية.
- `/readinessz` — يعرض تقرير JSON واضحًا بما اكتمل وما يزال مطلوبًا قبل الإطلاق.

يتحقق `/healthz` من ترتيب أقسام الصفحة، وعدد المهارات ومجموعات التقنيات والروابط، وترتيب المشاريع و`slug` ونوع المعاينة ومعرّفات أقسام دراسة الحالة وعدد الوسائط. يعيد حالة `Degraded` مع تفاصيل واضحة عند وجود اختلاف بين اللغتين.

أما `/readinessz` فلا يعامل المحتوى المؤجل كعطل تقني. بل يحصي جاهزية روابط التواصل، ودراسات الحالة، ووسائط المشاريع، وملفات السيرة PDF، وقناة مشاركة المعرفة والفيديوهات المختارة لكلتا اللغتين. يعيد `isReady: true` فقط بعد اكتمال جميع عناصر الإطلاق، مع قائمة `pending` دقيقة عند وجود نواقص. الاستجابة غير مخزنة مؤقتًا حتى تعكس آخر تعديل للمحتوى.

تعتمد روابط التواصل داخل تقرير الجاهزية على ترتيب الحقول المعتمد في ملفات المحتوى: البريد ثم LinkedIn ضمن `primaryLinks`، وGitHub ثم YouTube ثم Instagram ضمن `socialLinks`. يحمي مدقق المحتوى الثنائي هذا الترتيب بين اللغتين.

عند اختيار الإنجليزية يضيف الموقع `?lang=en` إلى الرابط ويحافظ عليها عند التنقل بين الصفحات، حتى يمكن نسخ رابط النسخة الإنكليزية ومشاركته وفهرسته بصورة مستقلة. العربية تبقى الرابط الافتراضي بدون معامل لغة.

## إضافة المحتوى مستقبلًا

معظم محتوى الموقع موجود في:

- `src/X7do0.Portfolio/Content/portfolio.ar.json`
- `src/X7do0.Portfolio/Content/portfolio.en.json`

إضافة مشروع أو مهارة أو تقنية جديدة تتم بتحديث ملفات المحتوى بدل إعادة بناء الصفحة أو تكرار المكونات. المشروع الجديد يظهر تلقائيًا في الصفحة الرئيسية وصفحته المستقلة وخريطة الموقع وبيانات JSON-LD المنظمة، ويدخل تلقائيًا ضمن تقرير الجاهزية.

أثناء التطوير، لا تُخزَّن ملفات المحتوى مؤقتًا، لذلك تظهر تعديلات JSON بعد إعادة تحميل الصفحة. عند وجود حقل أساسي فارغ أو `slug` مكرر، يعرض التطبيق خطأ واضحًا بدل تشغيل محتوى غير سليم.

## هوية المتصفح والتثبيت

- ملف الـManifest: `src/X7do0.Portfolio/wwwroot/site.webmanifest`
- أيقونة x7do0: `src/X7do0.Portfolio/wwwroot/icons/x7do0-mark.svg`
- ربط الأيقونة والـManifest وبيانات تطبيق الهاتف موجود داخل `Components/App.razor`.

يمكن تعديل اسم التطبيق المختصر والوصف وألوان التثبيت مركزيًا من ملف الـManifest، بدون تعديل صفحات الموقع.

## الاستضافة خلف Proxy أو Tunnel

القيمة الافتراضية آمنة ولا تثق بترويسات البروكسي:

```json
"Hosting": {
  "TrustForwardedHeaders": false
}
```

عند النشر خلف Reverse Proxy موثوق أو Cloudflare Tunnel يمكن تغييرها إلى `true` حتى تتولد روابط Canonical و`robots.txt` و`sitemap.xml` باستخدام البروتوكول والدومين العام الصحيحين. لا تُفعّل هذه القيمة عند تعريض التطبيق مباشرةً للإنترنت بدون Proxy موثوق.

- لم تُضف GitHub Actions أو CI.
- الاختبارات النهائية مؤجلة إلى مرحلة الإكمال النهائي حسب القرار المعتمد.
- روابط الحسابات والفيديوهات وملفات PDF الحقيقية ستُربط بعد اعتمادها.

- يمكن متابعة النواقص الحالية مباشرةً من `/readinessz` بدل الاعتماد على قائمة يدوية قد تصبح قديمة.
