# x7do0 Portfolio

البورتفوليو الرسمي لـ **حيدره مهند** — مطور برمجيات يركز على الـBackend وبناء الأنظمة.

الموقع Static ومهيأ للنشر المباشر على GitHub Pages، ويعتمد على Semantic HTML وModern CSS وVanilla JavaScript من دون تبعيات Production أو Build step.

## ما يقدمه الموقع

- صفحة رئيسية عربية/إنكليزية ضمن حاوية بعرض أقصى `1120px`.
- تعريف مباشر بالاسم والتخصص وقسم About وسيرة مختصرة داخل الصفحة.
- عرض مدمج لأربعة مشاريع بلقطات حقيقية ومعلومات مستندة إلى مستودعاتها.
- فتح الـInteractive Demos داخل صفحة كل مشروع فقط عبر `iframe` مؤجل التحميل.
- قسم مهارات بصري وتقنيات بعلامات سريعة القراءة.
- قسم تعلّم وتعليم يضم ثلاثة فيديوهات حقيقية، مع صورة معاينة وتحميل مشغّل YouTube بعد النقر فقط.
- معلومات تعليمية موثقة، وموقع جغرافي، وقنوات تواصل مهنية معتمدة.
- دعم RTL/LTR والموبايل و`prefers-reduced-motion`.
- دراسات حالة ثنائية اللغة لـEnterprise Workflow ومصروفي وأكاديمية البرمجة، مع 6–7 صور حقيقية لكل مشروع وLightbox قابل للوصول.
- صفحة Resume ثنائية اللغة وموسعة وقابلة للفهرسة.

## التشغيل محلياً

ملفات المحتوى تُحمّل عبر `fetch`، لذلك يجب تشغيل خادم Static:

```powershell
python -m http.server 8080
```

ثم افتح `http://localhost:8080/`.

## المسارات

- `/` و`/?lang=en` — الصفحة الرئيسية.
- `/projects/{slug}/` — تفاصيل المشروع ومكان تشغيل الـDemo داخل الصفحة.
- `/demos/{slug}/` — المحاكاة المستقلة المستخدمة داخل الـiframe.
- `/resume/` — السيرة داخل الموقع.
- `/404.html` — صفحة غير موجودة ثنائية اللغة.

المشاريع المعتمدة هي:

- `enterprise-workflow`
- `coding-academy`
- `mahsoob`
- `masroofi`

## إدارة المحتوى

المصدران المعتمدان للنصوص والبيانات:

- `content/portfolio.ar.json`
- `content/portfolio.en.json`

يجب تحديثهما معاً والحفاظ على نفس `slug` وترتيب المشاريع. بيانات الملف الشخصي والتعليم والتواصل والفيديوهات والسيرة موجودة في الملفين نفسيهما، ويجب أن تبقى متطابقة دلاليًا بين اللغتين.

روابط التواصل المعتمدة حاليًا هي بريد العمل وTelegram وGitHub وYouTube وInstagram. لا يضاف أي رابط اجتماعي أو عنوان شخصي غير معتمد. يبقى `resume.pdfUrl` فارغًا ويظل زر PDF مخفيًا إلى أن تعتمد نسخة PDF حقيقية.

فيديوهات قسم `knowledge.videos` تحتاج `id` و`title` و`category` و`description` و`url`. أول فيديو يحمل `featured: true` يظهر كالمادة الرئيسية. لا يُنشأ `iframe` عند فتح الصفحة؛ ينشئه `app.js` بعد ضغط زر التشغيل باستخدام `youtube-nocookie.com`، بينما تبقى صورة المعاينة خفيفة وسريعة.

لقطات المشاريع موجودة في `assets/projects/{slug}/`. لقطة محسوب تبقى محاكاة مصدرية مختصرة، أما Enterprise Workflow ومصروفي والأكاديمية فتستخدم شاشات فعلية من المصدر المدقق وببيانات تجريبية آمنة. كل عنصر `media` يحتاج `src` و`alt` و`caption` في اللغتين.

روابط `live` و`source` تُعرض كقرارات مستقلة عن المحاكاة. لا يُضاف رابط مصدر للمستودع الخاص بـEnterprise Workflow.

أدوات إعادة التقاط الصور:

- `tools/capture-case-study-media.mjs` لمصروفي والأكاديمية بعد تشغيل مصدرهما محلياً.
- `tools/capture-enterprise-media.mjs` لـEnterprise Workflow بعد تشغيل بيئة E2E المعزولة فقط وتوفير متغيرات `ENTERPRISE_E2E_EMPLOYEE_EMAIL` و`ENTERPRISE_E2E_MANAGER_EMAIL` و`ENTERPRISE_E2E_PASSWORD` لمستخدمين تجريبيين.

لا تستخدم أداة Enterprise مع بيانات تطوير أو إنتاج، ولا تضع أسراراً أو معلومات أشخاص حقيقيين داخل الصور.

## Interactive Demos

الـDemos محاكاة لأهم تدفق في كل مشروع وليست نسخاً كاملة من التطبيقات الأصلية. بياناتها تجريبية وحالتها محلية في المتصفح ولا تحتوي على حسابات أو Backend حقيقي.

- Enterprise Workflow: إنشاء طلب، إرساله، تبديل الدور، ثم الموافقة.
- Coding Academy: بطاقات موضوعات، درس، تمرين، ثم تحديث التقدم.
- Mahsoob: إضافة منتج، استلام المبلغ، وإصدار إيصال.
- Masroofi: إضافة مصروف، تحديث الرصيد، ثم حذف العملية.

## الاختبارات

```powershell
npm install
npm run test:e2e
```

تغطي Playwright الصفحة الرئيسية العربية والإنكليزية، تبديل اللغة بالاتجاهين، الملف المهني والتعليم والرتبة، قنوات التواصل المعتمدة، التحميل المؤجل لفيديوهات YouTube، عدم وجود Horizontal Overflow، انتقال التجربة إلى صفحة المشروع وفتحها هناك، السيرة الكاملة، التدفقات التفاعلية الأربعة، والبيانات المنظمة ومسارات SEO العامة.

## SEO والنشر

- `sitemap.xml` يفهرس الصفحة الرئيسية والسيرة وصفحات المشاريع.
- `robots.txt` يستبعد `/demos/` لأنها محاكاة وليست صفحات المحتوى الأساسية.
- النشر من جذر فرع `main` عبر GitHub Pages وملف `.nojekyll`.
