# x7do0 Portfolio

البورتفوليو الرسمي لـ **حيدره مهند** والهوية الرقمية **x7do0**.

## التقنية

- ASP.NET Core Blazor Web App
- .NET 10
- Interactive Server rendering
- محتوى عربي وإنكليزي منفصل وسهل التعديل
- تصميم RTL/LTR متجاوب
- صفحات مشاريع ديناميكية تعتمد على `slug`

## التشغيل محليًا

```bash
dotnet run --project src/X7do0.Portfolio/X7do0.Portfolio.csproj
```

## الصفحات الحالية

- `/` — الصفحة الرئيسية.
- `/projects/{slug}` — صفحة ديناميكية لأي مشروع موجود داخل ملفات المحتوى.
- `/resume` — السيرة الذاتية المبنية من المعلومات المعتمدة الحالية.

## إضافة المحتوى مستقبلًا

معظم محتوى الموقع موجود في:

- `src/X7do0.Portfolio/Content/portfolio.ar.json`
- `src/X7do0.Portfolio/Content/portfolio.en.json`

إضافة مشروع أو مهارة أو تقنية جديدة تتم بتحديث ملفات المحتوى بدل إعادة بناء الصفحة أو تكرار المكونات.

راجع الدليل التفصيلي:

- `docs/CONTENT_GUIDE.md`

## حالة التنفيذ

- التطوير يتم على فرع مستقل وDraft Pull Request.
- لم تُضف GitHub Actions أو CI.
- الاختبارات النهائية مؤجلة إلى مرحلة الإكمال النهائي حسب القرار المعتمد.
- روابط الحسابات والفيديوهات وملفات PDF الحقيقية ستُربط بعد اعتمادها.
