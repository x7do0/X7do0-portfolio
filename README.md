# Haidara Muhanned — Portfolio

البورتفوليو الشخصي والمهني لـ **حيدره مهند**، مطور برمجيات يركز على الـBackend وبناء الأنظمة والتطبيقات العملية.

**Live:** https://x7do0.github.io/X7do0-portfolio/

## المحتوى

- مشاريع مختارة مع صفحات مستقلة لكل مشروع.
- محاكاة تفاعلية مختصرة لأهم تدفقات بعض المشاريع.
- عرض للمهارات والتقنيات والخبرة العملية.
- قسم للتعلّم والتعليم ومحتوى من قناة YouTube.
- سيرة مهنية داخل الموقع.
- دعم العربية والإنكليزية وRTL/LTR والتصميم المتجاوب.

## المشاريع المعروضة

- **Enterprise Workflow** — نظام للطلبات والموافقات داخل الشركات.
- **X7do0 Academy** — منصة عربية لتعلّم البرمجة، مع Python متاح ومسارات إضافية قادمة.
- **Masroofi** — تطبيق لإدارة الدخل والمصروفات بُني حسب طلب عميل، مع بقاء البيانات محلياً على الجهاز.
- **Mahsoob** — نظام نقاط بيع عربي قيد التطوير للمتاجر الصغيرة في العراق.

## التقنيات

الموقع Static ومبني باستخدام **HTML, CSS, Vanilla JavaScript**، ومنشور عبر **GitHub Pages**. توجد اختبارات متصفح آلية باستخدام **Playwright** للتحقق من الصفحات والتجاوب والتجارب التفاعلية.

> بعض المشاريع المعروضة تملك مستودعات خاصة؛ البورتفوليو يعرض فقط المعلومات والوسائط والمحاكاة المناسبة للنشر العام.
